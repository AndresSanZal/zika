# 字卡 · Hanzi

Web app personal para estudiar chino: diccionario con hanzi, pinyin y significado en español, y flashcards en las que dibujas el carácter con el dedo y luego lo compruebas.

- Funciona sin conexión una vez instalada (Safari → Compartir → *Añadir a pantalla de inicio*).
- El vocabulario se publica en `vocab.json`; la app lo comprueba cuando hay conexión y añade lo nuevo sin tocar el progreso.
- El progreso de estudio se guarda solo en el dispositivo.
